# 🏦 Bank Fraud Detection: 

Решение задачи классификации мошеннических транзакций в условиях сильного дисбаланса классов.

## 🎯 Задача
Разработать модель для идентификации фрода, минимизирующую ложные срабатывания (False Positives), чтобы избежать блокировки честных клиентов банка.

## 🛠 Технологический стек
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
* **ML Модели:** CatBoost
* **Методы ресемплинга:** ADASYN

---

## 🚀 Ключевые этапы реализации

### 1. Feature Engineering & Analysis
* Проведен анализ корреляции признаков для устранения избыточности.
* Созданы дополнительные признаки на основе структуры транзакций.
* Визуализировано распределение классов (обнаружен критический дисбаланс).

### 2. Эксперименты с дисбалансом
Было проведено сравнение двух подходов для выравнивания весов классов:
1.  **ADASYN** (генерация синтетических данных).
2.  **CatBoost `auto_class_weight`** (взвешивание функции потерь).

> **Итог:** Выбран встроенный параметр CatBoost, так как при идентичном качестве метрик он обеспечивает более высокую скорость обучения и стабильность модели.

### 3. Оптимизация порога (Threshold Tuning)
Стандартный порог 0.5 был заменен на оптимальный для максимизации **F1-Score**, что позволило достичь баланса между полнотой (Recall) и точностью (Precision).

---

## 📊 Итоговые метрики
Модель показала высокую разделительную способность:
