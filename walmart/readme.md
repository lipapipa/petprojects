# 🛒 M5 Forecasting: Прогнозирование продаж (LightGBM)

В этом проекте решается задача прогнозирования ежедневных продаж товаров в розничных магазинах (Walmart). Используются исторические данные о продажах, календарные события и цены.

## 🎯 Цель проекта
Построить модель машинного обучения, способную предсказывать количество проданных единиц товара (unit sales) на будущий период (28 дней), минимизируя ошибку прогноза.

## ⚙️ Этапы предобработки данных (Feature Engineering)

1.  **Оптимизация памяти:** Приведение типов `int64` -> `int16`, `float64` -> `float32` для работы с большим объемом данных (~59 млн строк).
2.  **Трансформация данных:** Преобразование из широкого формата (wide) в длинный (melt) для временных рядов.
3.  **Обогащение данных:**
    * Объединение с данными календаря (события, дни недели).
    * Объединение с данными о ценах (`sell_price`).
    * Обработка пропусков в ценах (`bfill`).
4.  **Генерация признаков:**
    * **Лаги (Lags):** Сдвиги на 28 и 35 дней (`lags28`, `lags35`).
    * **Скользящие средние:** Rolling mean по лагам (`rlag7_lag28`, `rlag7_lag35`).
    * **Временные признаки:** Дней с последней продажи (`day_since_last_sale`).
    * **Target Encoding:** Средние продажи по товару и по событиям.

---

## 🤖 Модель (LightGBM)

Использовался **LGBMRegressor** со следующими параметрами:
* `objective`: regression
* `learning_rate`: 0.03
* `num_leaves`: 63
* `lambda_l2`: 0.1 (регуляризация)
* `min_data_in_leaf`: 100

Обучение проводилось на выборке из последних 10 миллионов записей с разбиением 80/20 (Time-based split).
